# Obsidian + Codex

Obsidian is the memory layer. Codex is the execution layer.

The useful pattern is simple:

- Capture raw thoughts quickly.
- Let notes accumulate real context.
- Use Codex to search, synthesize, edit, and operationalize the context.
- Keep the system local, inspectable, and boring enough to maintain.

The best version of this is not a giant agent. It is a small set of reliable workflows that make the existing vault more useful every day.
